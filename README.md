# Classificador de Idade 🐍

Projeto desenvolvido durante meus estudos de Python, com o objetivo de praticar os fundamentos da linguagem e desenvolver minha lógica de programação.

## 📌 Sobre o projeto

O programa solicita a idade do usuário e realiza uma classificação de acordo com sua faixa etária.

Também verifica se a idade informada é válida.

## ⚙️ Tecnologias utilizadas

- Python 3
- Estruturas condicionais (`if`, `elif`, `else`)
- Funções (`def`)
- Entrada de dados (`input`)
- Conversão de tipos (`int`)

## 📋 Classificações

| Idade | Classificação |
|---|---|
| Menor que 0 | Idade inválida |
| 0 a 12 | Criança |
| 13 a 17 | Adolescente |
| 18 a 59 | Adulto |
| 60 ou mais | Idoso |

## 💻 Exemplo de execução

```text
Digite sua idade: 20
Você é um adulto.
```

Outro exemplo:

```text
Digite sua idade: -5
Idade inválida
```

## 🧠 Conceitos praticados

- Declaração e chamada de funções.
- Armazenamento de dados em variáveis.
- Recebimento e conversão de informações.
- Tomada de decisões utilizando estruturas condicionais.
- Validação de dados fornecidos pelo usuário.
